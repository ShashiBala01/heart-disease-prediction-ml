# ❤️ Heart Disease Prediction using Machine Learning

## 📌 Project Overview

This project aims to predict whether a patient is likely to have heart disease based on medical attributes using Machine Learning techniques.

The dataset was analyzed, cleaned, and explored using various visualization techniques before training multiple classification models.

---

## 🎯 Objectives

- Analyze heart disease data.
- Perform data cleaning and exploratory data analysis (EDA).
- Train multiple machine learning models.
- Compare model performance.
- Identify the most important features affecting heart disease prediction.

---

## 📊 Dataset Information

- Total Records (after cleaning): **918**
- Features: **11**
- Target Variable:
  - **0 = No Heart Disease**
  - **1 = Heart Disease**

---

## 🔍 Exploratory Data Analysis

The following analyses were performed:

- Target Distribution
- Age Distribution
- Cholesterol Distribution
- Gender vs Heart Disease
- Age vs Heart Disease
- Correlation Heatmap
- Outlier Analysis
- Feature Importance Analysis

---

## 🤖 Machine Learning Models Used

### 1️⃣ Logistic Regression

**Accuracy:** 84.78%

### 2️⃣ Decision Tree

**Accuracy:** 82.61%

### 3️⃣ Random Forest

**Accuracy:** 88.04%

---

## 📈 Model Comparison

| Model | Accuracy |
|---------|---------|
| Logistic Regression | 84.78% |
| Decision Tree | 82.61% |
| Random Forest | 88.04% |

✅ Random Forest achieved the highest accuracy and was selected as the best-performing model.

---

## ⭐ Feature Importance

The most influential features were:

- ST Slope
- Oldpeak
- Cholesterol
- Exercise Angina
- Maximum Heart Rate

---

## 📝 Conclusion

A Heart Disease Prediction system was developed using Machine Learning techniques.

Among all the models tested, **Random Forest** delivered the best performance with an accuracy of **88.04%**.

Feature importance analysis revealed that **ST Slope, Oldpeak, Cholesterol, Exercise Angina, and Maximum Heart Rate** were the most significant predictors of heart disease.
